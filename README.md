Dice Roller Program 🎲

A simple dice rolling program I made using Python to practice loops, dictionaries, and random numbers.

The program lets the user choose how many dice they want to roll. It generates random numbers between 1 and 6, displays each die using ASCII art, and calculates the total.

 Features

- Roll multiple dice at once
- Random numbers from 1 to 6
- Visual representation of each die in the terminal
- Calculates the total of all dice rolled
- Simple command-line interface

Technologies that I Used

- Python
- Random module (built into Python)

 How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the Python file:

python DiceRoller.py

Replace DiceRoller.py with your actual filename if it's different.
